# Ttuk Ttak · 뚝딱

아이디어를 코드로, 뚝딱. Claude Code와 Codex에서 PRD·설계·구현·리뷰·검증·PR까지 처리합니다.

플러그인 식별자는 `ttuk-ttak`, 저장소는 `rnqhstmd/ttutak`입니다. 새 버전이 원격 저장소에 반영된 뒤 설치합니다.

```text
/plugin marketplace add rnqhstmd/ttutak
/plugin install ttuk-ttak@ttuk-ttak
/ttuk-ttak:setup
```

18개 스킬과 17개 에이전트를 제공합니다. 일반 개발은 `dev`, 테스트부터 개발은 `tdd`, 완료 검증은 `verify`로 요청합니다.

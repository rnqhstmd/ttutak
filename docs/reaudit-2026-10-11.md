작성일: 2026-10-11. 기준 upstream은 oh-my-gx v1.33.0 (`e807c65`), 재검증 시작 커밋은 `a6d885d`다.

## 결론과 범위

원본의 17개 스킬에 대한 실행 규약 이식은 확인했다. 기존 Spring 전용 `test`를 추가한 총 18개 스킬을 배포한다. **두 하네스에서 모든 스킬의 실제 모델 실행 결과가 동일하다는 의미는 아니다.** 소스 비교, 오프라인 계약, native 로더와 인증 모델 실행은 각각 다른 증거다.

## 발견한 결함과 수정

- 보호 훅이 커밋 메시지 안의 `-C`를 Git 저장소 옵션으로 해석했다. main에서 `git commit -m 'fix -C /tmp/nonexistent-parity-dir'`를 허용하는 회귀를 재현했다. 셸 명령을 실행하지 않는 인용 인식 토큰 파서로 바꾸어 **Git subcommand 이전 전역 옵션만** 저장소 경로에 반영한다. 보호 브랜치와 pending verify 회귀 사례를 추가했다.
- 홈페이지의 Ralph 종료 토큰을 `<ralph>COMPLETE</ralph>`로 바로잡았다. 소비 프로젝트에 없는 상대 러너 경로 대신 설치된 플러그인 경로를 안내하고, Codex의 필수 `GX_RALPH_ITERATE_SKILL`도 안내한다.
- HTML에서 Markdown 문서로 향하는 링크를 Pages 출력 경로에 맞췄다. Markdown 문서 자체의 상대 링크는 GitHub Pages relative-links 처리를 따른다.
- 활성 가이드의 `/gx-` 명령, Google Chat 중심 초기 설정, 언어 지원 한정, Codex cross-review 안내를 현재 규약에 맞췄다. 웹훅을 커밋하라는 잘못된 안내를 제거했다.
- golden 시나리오의 기본 TDD/격리 경로 모순과 17개 스킬 표기를 수정했다. upstream 과거 smoke 결과와 현재 실행하지 않은 시나리오를 분리했다.

## 하네스 검증

- Claude Code 2.1.227: manifest native 검증과 `--plugin-dir` 인벤토리에서 스킬 18개·에이전트 17개·훅 2개 확인. 현재 미로그인 상태라 실제 모델 전체 흐름은 실행하지 못했다.
- Codex 0.159.2: 완전한 Git archive를 임시 디렉토리로 내보내고 **임시 marketplace만 local 상대 경로로 지정**하여 app-server `plugin/read`로 스킬 18개와 훅 정의를 읽었다. 사용자 플러그인을 설치하거나 전역 설정을 바꾸지 않았다. 결과의 installed/enabled는 false이며, 설치·훅 신뢰·런타임 게이트 적용의 증거로 사용하지 않는다.
- PATH의 npm Codex는 native 실행 파일 부재로 실행되지 않으므로, 검증에는 앱에 동봉된 실행 파일을 사용했다.

인증된 Codex를 `exec --ephemeral --ignore-user-config --json -s workspace-write`로 임시 소비 프로젝트에서 실행하여 다음 두 가지 **현재 소스 스킬** 시나리오를 확인했다. 설치 플러그인의 실행 증거로 확대하지 않는다.

| 실제 모델 시나리오 | 관찰한 결과 | 이번에 확인하지 않은 경로 |
|---|---|---|
| humanizer --audit | SKILL/runtime/패턴 참조 읽기, P1 3개 감지, summary.md 저장, 원문 SHA-256 불변 | rewrite·strict·역할 자식 실행 |
| verify --non-interactive | SKILL/runtime 읽기 후 config 부재로 Step 1 BLOCKED, 소비 파일 불변 | 테스트 통과·지문·커밋 허용·신뢰된 훅 |

두 프로세스 모두 exit 0이다. verify의 exit 0은 모델 프로세스 정상 종료이며 게이트 통과를 뜻하지 않는다. trace·결과는 임시 검증 디렉토리 `ttuk-reaudit-model-kq98bz4c`에 보관했다.

## 수정 후 자동 검사와 독립 리뷰

- Python 전체: 165개 실행, 실패 0, Windows 전용 5개 skip, **160개 통과**.
- 최신 보호 훅 48개, 기존 ttutak 보호 훅 17개, 정합성 린트 36개 통과.
- Ralph 러너 mock 36개, 행동 테스트 러너 mock 30개 통과. 실제 에이전트 행동의 전체 성공률을 뜻하지 않는다.
- Codex 생성 리소스 `--check`, Bash 3.2 구문·실행, `git diff --check` 통과.
- 별도 리뷰어가 default/jq 없는 PATH 각각 24개, 총 48개 훅 사례를 독립 실행해 통과를 확인했다. 직접 명령·인용 메시지·복합 shell wrapper와 오탐 사례를 포함한다.
- 문서 리뷰에서 현재 결과와 upstream 과거 기록을 분리했으며 HTML 앵커 누락·중복 ID가 없다. 브라우저에서 설치 영역 표시·메뉴 이동·Codex FAQ 펼침과 수정된 문서 href를 확인했다. **Jekyll 전체 빌드는 실행하지 않았으며**, `.html` 링크는 Pages 생성 규칙과 대응 Markdown 파일을 정적으로 확인했다.
